校园网认证 + 单线多拨 完全指南

一根网线拨多个号，带宽叠加 + 自动认证 + 掉线保活，零基础也能看懂

OpenWrt / iStoreOS 纯 Python · 零依赖 双拨 / 四拨 AES-128-ECB

这是什么？（说人话）

一句话：让你的路由器「一根网线同时拨多个号」，把校园网带宽叠加起来，而且掉线了自动重新登录。

举个栗子 🌰：

  • 宿舍只有一根网线，认证后单账号下载比如 40 Mbps
  • 本方案让这根线「分身」成 2 个（甚至 4 个）虚拟接口，各自认证
  • 下载速度翻倍到 80 Mbps（每个虚拟接口有独立带宽配额）

核心概念（1 分钟看懂）

① 拨号

校园网插线后，路由器 WAN 口通过 DHCP 自动拿到 IP（如 10.0.0.1），这个过程就是一次拨号。

② 单线多拨

通过 macvlan 技术，在同一根物理网线上创建多个「虚拟网卡」，每个有独立 MAC 和 IP，等于「一根线拨多个号」。

③ 认证

校园网要先登录认证（输学号密码），认证系统记录「哪个 IP/MAC 已认证」后才放行上网。

④ mwan3

多 WAN 负载均衡插件，把流量自动分配到多个拨号，让下载速度叠加。

⑤ keep 保活

看门狗脚本，每 15 秒检查一次，掉线自动重连，让你一直在线。

分步教程（手把手）

登录路由器

Windows 按 Win + R，输入 cmd 回车：

ssh root@192.168.1.1

输入密码（屏幕不显示是正常的），看到 root@iStoreOS:~# 就成功了。

创建虚拟接口（macvlan）

# 看物理 WAN 口名字
ip link show | grep eth

# 假设是 eth0，创建 2 个虚拟网卡（双拨）
ip link add link eth0 eth0mac0 type macvlan
ip link add link eth0 eth0mac1 type macvlan

四拨就再加 eth0mac2、eth0mac3 两个。

配置 mwan3

浏览器打开 192.168.1.1，进「网络 → 负载均衡」，按四层配：

  1. 接口：新建 vwan0、vwan1，绑定 eth0mac0、eth0mac1，track_ip 填 www.baidu.com
  2. 成员：每个接口建一个 member
  3. 策略：建 balanced，加入两个 member
  4. 规则：目标 0.0.0.0/0，策略选 balanced

上传认证脚本

scp 2wan/campus_auth_openwrt.py root@192.168.1.1:/zy/campus_auth.py

四拨就传 4wan/ 里的同名文件。

配置账号密码

vi /zy/campus_auth.py

找到 INTERFACES，把 YOUR_USERNAME / YOUR_PASSWORD 改成真实账号密码。

vi 操作：按 i 编辑 → 改完按 Esc → 输入 :wq 回车保存。

部署保活服务

scp 2wan/campus_auth.initd root@192.168.1.1:/etc/init.d/campus_auth
chmod +x /etc/init.d/campus_auth
/etc/init.d/campus_auth enable
/etc/init.d/campus_auth start

装依赖 + 测试

opkg update && opkg install curl
python3 /zy/campus_auth.py

预期输出：[vwan0] 成功 - 认证成功！ 和 [vwan1] 成功，双拨就通了。

日常使用

部署完完全不用管：掉线自动重连、重启自动启动、日志自动轮转。

python3 /zy/campus_auth.py status    # 查看认证状态
python3 /zy/campus_auth.py logoff    # 手动下线
cat /tmp/campus_auth.log             # 查看日志

常见问题（FAQ）

问题原因 / 解决
认证「重试3次仍失败」认证服务器地址不对，或网线断了
下载叠加、上传没叠加正常现象，上行按账号限速，四拨用 2 账号才能叠加
认证成功但网速慢检查 mwan3 balanced 策略和规则配对
重启后失效确认 campus_auth 已 enable
插手机热点后认证连不上需部署 99-campus-auth 静态路由

技术细节

密码加密

认证系统密码加密（从前端 crypto.js 逆向）：AES-128-ECB-ZeroPadding，明文 = 4 位随机 salt + 密码。

keep 检测

状态码含义动作
204在线不动作
302认证掉线自动重连
000/err网络抖动跳过

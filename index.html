校园网认证 + 单线多拨方案

针对 raasportal 认证系统的校园网，实现单线多拨带宽叠加、自动认证、掉线保活

OpenWrt / iStoreOS 纯 Python · 零依赖 双拨 / 四拨 AES-128-ECB

功能特性

  • 纯 Python AES 加密：密码加密逻辑内置，无需第三方库
  • 单线多拨：双拨 / 四拨，每个拨号接口独立认证、绑定源接口
  • keep 保活：HTTP 204/302 精确检测认证状态，掉线自动重连
  • 日志自动轮转：日志超限自动截断，不占内存
  • 静态路由：多 WAN 场景防止认证服务器被抢

技术原理

密码加密

从前端 crypto.js 逆向得到：AES-128-ECB-ZeroPadding，明文为「4 位随机 salt + 密码」。

keep 检测机制

状态码含义动作
204认证在线不动作
302认证掉线（Portal 重定向）自动重连
000/err网络抖动跳过，避免误判

静态路由

多 WAN 场景下，认证服务器（内网）可能被其他 WAN 的 default 路由抢走。99-campus-auth 用 prio 50 的 ip rule 锁死认证服务器走校园网接口。

快速部署

# 1. 上传主脚本（双拨为例）
scp 2wan/campus_auth_openwrt.py root@<路由IP>:/zy/campus_auth.py

# 2. 部署 init.d 服务
scp 2wan/campus_auth.initd root@<路由IP>:/etc/init.d/campus_auth
chmod +x /etc/init.d/campus_auth
/etc/init.d/campus_auth enable
/etc/init.d/campus_auth start

# 3. 安装依赖
opkg update && opkg install curl
⚠️ 部署前需把脚本里的 YOUR_USERNAME / YOUR_PASSWORD 改成真实账号密码，并修改 BASE_URL（认证服务器地址）、AES_KEY（需自行逆向）。

双拨 / 四拨

每个账号限 2 台设备：

  • 双拨（2wan/）：1 个账号认证 2 个接口
  • 四拨（4wan/）：2 个账号认证 4 个接口，把「待填账号2」改成真实值

仅供学习研究，请遵守所在校园网的使用规范。
